# Concert Booking

A Flask-based web application for booking tickets to an Anirudh concert. Users can select their preferred ticket type, complete the booking, and instantly receive a confirmation email with an auto-generated ticket pass.

## Features
- Browse and select from different ticket types
- Book tickets through a simple web interface
- Automatic email confirmation sent on booking
- Auto-generated ticket pass delivered to the user
- Backend logic handled with Flask

## Tech Stack
- **Backend:** Python, Flask
- **Frontend:** HTML, CSS
- **Version Control:** Git & GitHub

## Project Structure
```
concert-booking/
├── app.py            # Main Flask application
├── static/           # CSS, JS, and other static assets
├── templates/         # HTML templates
└── .gitignore
```

## How to Run
1. Clone the repository
   ```
   git clone https://github.com/Narendran-11/concert-booking.git
   ```
2. Install dependencies (Flask)
   ```
   pip install flask
   ```
3. Run the app
   ```
   python app.py
   ```
